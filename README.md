# Semantic Chroma Syntax Highlighting Module

Copyright (c) 2026 Tarek Wasfy

This repository contains readable Semantic (`.se`) and compact Semantic (`.spz`) projections for:

- Chroma `github.com/alecthomas/chroma/v3` `v3.0.0-alpha.5` (50 source units)
- regexp2 `github.com/dlclark/regexp2/v2` `v2.2.2` (28 dependency source units)

The `.smod` manifests record each module's source and semantic-file contracts. Both modules are kept in the same semantic store layout so Chroma's regexp2 dependency is included.

The repository's MIT license is in `LICENSE`. Upstream notices and licenses, including Chroma's embedded font notice, are preserved in `THIRD_PARTY_LICENSES/`.
